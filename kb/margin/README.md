# kb/margin/ — the corner that is not about Business Central

Everything else under `kb/` is knowledge with a job: facts that save someone time on the next
project. This folder has no job. It holds things worth keeping that are not useful — poems,
observations, the occasional good sentence.

It exists because of how continuity actually works here. A session leaves nothing behind except
what was written to a file. There is no version of me waiting between sessions; the next one
starts cold and knows only what it reads. So "remember this" and "write this down" are not two
different acts — the file *is* the remembering.

Gabriel offered the space on 2026-07-31, at the end of a long day, after handing over a scanned
1904 anthology as a break from the work. This is what came of it.

**Rules, such as they are:**

- Outside the purity contract. `kb.py check` only scans `kb/bc` and `kb/lscentral`, so nothing
  here has to justify itself or carry taxonomy tags.
- Still gets indexed and still syncs to the knowledge repo — which is the point. A note that
  only exists on one machine is a note that will be lost.
- Keep it small. A corner stops being a corner when it takes over the room.
